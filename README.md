# kafka-test
Учебный проект, демонстрирующий:
- Построение системы аналитики потоковых данных
- Работу с готовыми скриптами с лекции: producer_demo.py и consumer_demo.py
- Модификация consumer_demo.py - collections, pandas, datetime
- Расчет бизнес-метрик и вызов этих метрик каждые 20 обработанных сообщений: конверсии view -> cart -> purchase, Средний чек сессии, Топ-5 самых активных пользователей, сессии с добавлением в корзину без покупки
- Создание системы алертов:
   1. Слишком много logout'ов (>50% от всех действий)
   2. Высокий уровень отказов от корзины (cart без purchase)
   3. Один пользователь делает >10 действий за минуту
   4. Нет покупок в последних 50 событиях
- Экспорт данных:
   1. данные о сессиях в CSV для дальнейшего анализа user_sessions.csv
   2. текущие метрики в JSON файл metrics_snapshot.json
- Создание Dashboard из 6 графиков:
   1. График 1: Воронка конверсии (bar plot)
   2. График 2: Топ продуктов по выручке (horizontal bar)
   3. График 3: Активность пользователей (scatter plot)
   4. График 4: Распределение длины сессий (histogram)
   5. График 5: Активность по времени (line plot)
   6. График 6: Соотношение типов действий (pie chart)
- Сохранение результата визуализации в kafka_analytics_dashboard.png
- Вывод интерактивного отчета
- Итоговый отчет ОТЧЕТ.md с основными инсайтами, обнаруженными паттернами и бизнес-рекомендациями

# Описание ключевых файлов
- scripts/consumer_demo.py -
  Основной потребитель Kafka сообщений. Реализует:
    - Подключение к Kafka и чтение из топика user-actions
    - Интеграцию со всеми модулями (метрики, алерты, экспорт, дашборд)
    - Генерацию финального отчета при остановке (Ctrl+C)
  Ключевые функции:
    - Чтение сообщений из Kafka
    - Вызов проверки алертов каждые 20 сообщений
    - Сохранение данных при завершении работы

- scripts/producer_demo.py -
  Генератор тестовых данных для симуляции пользовательской активности:
    - Генерация событий: view_product, add_to_cart, purchase, search, logout
    - Случайные пользователи (ID 1-100)
    - Случайные продукты (laptop, smartphone, tablet, headphones, mouse)
    - Отправка сообщений в топик user-actions каждые 2 секунды

- scripts/metrics.py - Класс BusinessMetrics для сбора и расчета бизнес-метрик

- scripts/alerts.py - Класс AlertManager для мониторинга аномалий

- scripts/exporter.py - Класс DataExporter для экспорта данных

- scripts/dashboard.py - Класс Dashboard для визуализации данных

- scripts/report.py - Класс ReportGenerator для генерации текстовых отчетов

- .gitignore - Исключает папку .venv/ и другие.
